🚀 1인 창업 AI 자동화 풀스택 가이드북

혼자서 기획, 디자인, DB 구축까지 100% 자동화하는 깃허브 마스터 가이드

1. 💡 왜 이 도구들의 조합이 강력한가?

보통 1인 창업자들은 무거운 상용 프로그램(예: 포토샵, 엑셀)에 의존합니다. 하지만 이들은 무겁고, 느리며, '자동화(스크립팅)'가 매우 어렵습니다. 우리가 구축한 조합은 "각 분야의 가장 가볍고 빠른 오픈소스(명령어 도구)들을 레고 블록처럼 조립하는 방식"입니다.

  • 텍스트 처리 및 기획: AI 에이전트(LLM)가 담당하여 사람의 두뇌 역할을 합니다.
  • 디자인(카드뉴스): 파이썬의 Pillow 라이브러리가 담당하여, 수백 장의 이미지를 1초 만에 찍어냅니다 (포토샵 대체).
  • 데이터 보관(DB): 엑셀 파일이 깨지거나 엉키는 것을 방지하기 위해 가벼운 SQLite와 sqlite-utils를 사용하여 안전한 영구 보관소 역할을 합니다.
핵심 파이프라인: "기획(AI) ➡️ 제작(Python) ➡️ 저장(SQLite)" 이라는 과정이 코드 한 줄로 실행되는 엄청난 효율을 냅니다.

2. 📥 사용된 핵심 깃허브 도구들의 출처와 설치법

① 터미널 생산성 도구 모음 Rust 기반

기존의 느린 윈도우 기본 명령어들을 대체하기 위해 깃허브에서 스타를 수만 개씩 받은 초고속 도구들입니다.

  • ripgrep: 텍스트 검색 1위 (BurntSushi)
  • eza: 디렉토리 목록 예쁘게 보기 (eza-community)
  • zoxide: 스마트한 폴더 이동 (ajeetdsouza)

② 초고속 파이썬 패키지 매니저: uv Astral

파이썬 환경 설정은 매우 복잡합니다. 하지만 uv를 사용하면 가상환경을 일일이 만들지 않아도, 스크립트 실행 시 필요한 라이브러리(Pillow, pandas 등)를 0.1초 만에 자동으로 다운로드하고 실행해 줍니다.

③ 깃허브 인기 DB 도구: sqlite-utils Simon Willison

복잡한 SQL 쿼리문을 몰라도, 터미널 명령어 한 줄로 DB에 데이터를 넣고, 검색하고, 엑셀이나 JSON으로 뺄 수 있게 해주는 마법 같은 도구입니다.

3. ⚙️ 전체 파이프라인 결합 및 사용 방법

실제 startup_automation_db 폴더 안에서 각 단계가 어떻게 맞물려 돌아가는지 설명합니다. 터미널을 열고 아래 명령어들을 따라 해보세요.

Step 1. 기획안 및 에셋 구워내기 (Python 스크립트 실행)

# uv가 필요한 파이썬 라이브러리를 임시로 즉시 다운받아 스크립트 실행
uv run --with pandas --with openpyxl --with Pillow init_db.py

동작 결과: cardnews_output 폴더에 이미지가 렌더링 되고, startup_data.db와 workflow_record.xlsx가 생성(업데이트) 됩니다.

Step 2. 로컬 DB 터미널에서 장난감처럼 다루기 (sqlite-utils)

# 1. 내 DB에 어떤 테이블들이 있는지 확인하기
sqlite-utils tables startup_data.db

# 2. 카드뉴스 텍스트가 DB에 잘 들어갔는지 표(table) 형태로 보기
sqlite-utils rows startup_data.db cardnews_slides -t

# 3. 통째로 JSON 파일로 내보내기
sqlite-utils rows startup_data.db workflow_records --json > export.json

🎯 요약

이 폴더 하나가 대표님의 '미니 데이터센터'이자 '자동화 공장'입니다. 데이터가 필요할 땐 sqlite-utils로 꺼내보고, 렌더링을 다시 하고 싶을 땐 init_db.py를 살짝 바꿔서 uv run으로 실행시키면 됩니다.
